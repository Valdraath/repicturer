# Models

The model folders (`models-*`, about 400 MB) are not stored in this repository. They are in every release download
(RePicturer-windows.zip / RePicturer-linux.zip).

To run a program built from source, copy the `models-*` folders of a release next to it.

Where every model comes from, its license and what was changed: see `THIRD_PARTY_LICENSES.md` and the `LICENSE.txt`
inside the model folders of a release.
