# Руководство по командной строке RePicturer (Windows)

`repicturer-cli.exe` — это конвертер, который работает за окном RePicturer. Его можно запускать и самостоятельно, в скрипте
или пакетном файле, чтобы обрабатывать изображения, не открывая программу. Он умеет всё, что умеет окно: модели ИИ,
«Масштаб - без ИИ», все пункты настроек, папки и списки файлов. Это руководство для **Windows**; руководство для Linux —
[Russian-Linux.md](Russian-Linux.md).

## 1. Начало работы

1. Откройте папку RePicturer (ту, где лежат `RePicturer.exe` и `repicturer-cli.exe`).
2. Щёлкните адресную строку Проводника, введите `cmd` или `powershell` и нажмите Enter. В этой папке откроется окно
   командной строки.
3. Выполните первую обработку:

   ```
   repicturer-cli.exe -i photo.jpg -o photo-2x.png
   ```

   В **PowerShell** перед именем нужно добавить `.\`:

   ```
   .\repicturer-cli.exe -i photo.jpg -o photo-2x.png
   ```

4. Посмотрите все параметры:

   ```
   repicturer-cli.exe -h
   ```

Без других параметров используется режим **Очистка и увеличение - ИИ**, 2x, уровень шума 0, модель `models-cunet`, на первом GPU.

**Пути с пробелами** нужно брать в кавычки: `-i "C:\My Pictures\cat.png"`. Модель можно указать только именем папки
(`-m models-realcugan-se`): она найдётся рядом с `repicturer-cli.exe`, в какой бы папке ни была командная строка.

## 2. Четыре режима

| Режим в окне | Значение `-M` | Что делает |
|---|---|---|
| Очистка и увеличение - ИИ | `denoise-scale` | убирает шум / артефакты JPEG и увеличивает с помощью модели ИИ |
| Увеличение - ИИ | `scale` | увеличивает с помощью модели ИИ, без шумоподавления |
| Очистка от шума - ИИ | `denoise` | убирает шум, размер не меняется |
| Масштаб - без ИИ | `non-ai-scale` | меняет размер классическим фильтром (Lanczos, Bicubic, Jinc...), без модели |

Без `-M` режим определяется другими параметрами, как в waifu2x-ncnn-vulkan: `-n -1` — только увеличение, `-s 1` — только
шумоподавление, всё остальное — шумоподавление и увеличение.

## 3. Примеры

**Аниме-картинка, 2x, Real-CUGAN SE с лёгким шумоподавлением:**

```
repicturer-cli.exe -i art.png -o art-2x.png -m models-realcugan-se -n 1 -s 2
```

**Фото шириной ровно 3840 пикселей (высота по пропорциям), NMKD Superscale:**

```
repicturer-cli.exe -i photo.jpg -o photo-4k.png -M scale -m models-nmkd-superscale -W 3840
```

**Ровно 1920 x 1080 (растягивается до этого размера, как в waifu2x-caffe):**

```
repicturer-cli.exe -i shot.png -o shot-1080p.png -M scale -m models-realesr-animevideov3 -W 1920 -H 1080
```

**Только убрать артефакты JPEG, размер не менять:**

```
repicturer-cli.exe -i scan.jpg -o scan-clean.png -M denoise -n 2 -m models-cunet
```

**ИИ 2,25x с более резким уменьшением после обработки (Lanczos 4 отвода с антирингом):**

```
repicturer-cli.exe -i art.png -o art.png -M scale -m models-realcugan-se -s 2.25 -F lanczos -T 4 -a relaxed
```

**Пиксель-арт, 4x, без ИИ (чёткие пиксели):**

```
repicturer-cli.exe -i sprite.png -o sprite-4x.png -M non-ai-scale -F nearest -s 4
```

**Фото, 1,5x без ИИ, Lanczos 3 отвода с антирингом:**

```
repicturer-cli.exe -i photo.jpg -o photo-15.png -M non-ai-scale -F lanczos -T 3 -a relaxed -s 1.5
```

**Уменьшить изображение вдвое в линейном свете:**

```
repicturer-cli.exe -i big.png -o small.png -M non-ai-scale -F catrom -s 0.5 --linear-light
```

**Игровой фон с бандингом (небо ступеньками), ИИ 2x, устранение бандинга перед ИИ:**

```
repicturer-cli.exe -i sky.png -o sky-2x.png -m models-realcugan-se -s 2 --deband medium
```

**Уменьшить фото с плавными градиентами: линейный свет и дизеринг диффузией ошибки:**

```
repicturer-cli.exe -i photo.png -o photo-small.png -M non-ai-scale -F catrom -s 0.5 --linear-light --dither error-diffusion
```

**Вся папка, включая вложенные, в WebP, пропуская уже обработанные изображения:**

```
repicturer-cli.exe -i D:\Pictures -o D:\Pictures-2x -r -k -f webp -q 90 -m models-realcugan-se -s 2
```

**На CPU (без GPU), 8 ядер:**

```
repicturer-cli.exe -i art.png -o art-2x.png -g -1 -j 1:8:2
```

## 4. Все параметры

### Вход и выход (все режимы)

| Параметр | Значение |
|---|---|
| `-i`, `--input path` | входное изображение или папка |
| `-o`, `--output path` | выходное изображение или папка |
| `-r`, `--recursive` | обрабатывать и вложенные папки, сохраняя их структуру |
| `-l`, `--extensions list` | расширения, которые читаются из папки, например `png:jpg:jpeg:webp` (по умолчанию: все файлы в ней; укажите, если в папке есть и другие файлы) |
| `-L`, `--file-list file` | текстовый файл UTF-8, в каждой строке пара `вход<TAB>выход` (см. раздел 6) |
| `-k`, `--no-overwrite` | пропускать изображения, для которых выходной файл уже есть (он сохраняется); пункт окна *Не перезаписывать существующие файлы* |
| `-f`, `--format fmt` | `png` `jpg` `webp` `bmp` `jp2` `sr` `tif` `hdr` `exr` `ppm` `tga` `gif` (по умолчанию: расширение выходного файла, иначе png). Анимированные GIF / WebP остаются анимированными |
| `-q`, `--quality q` | jpg 0-100 (по умолчанию 100), webp 1-100 или 101 = без потерь (по умолчанию 101), tga 0 / 1 = RLE выкл. / вкл. |

### Режим и размер (все режимы)

| Параметр | Значение |
|---|---|
| `-M`, `--mode mode` | `denoise-scale`, `scale`, `denoise` или `non-ai-scale` (раздел 2) |
| `-s`, `--scale r` | коэффициент масштаба, любое положительное число: `2`, `1.5`, `0.5` (по умолчанию 2) |
| `-W`, `--width w` | выходная ширина; высота по пропорциям, если не задан `-H` |
| `-H`, `--height h` | выходная высота; ширина по пропорциям, если не задан `-W` |
| `-W` и `-H` вместе | ровно эта ширина x высота |

### Режимы с ИИ (`denoise-scale`, `scale`, `denoise`)

| Параметр | Значение |
|---|---|
| `-m`, `--model path` | папка модели (по умолчанию `models-cunet`). Движок определяется папкой: `models-cunet`, `models-upconv_7_*`, `models-upresnet10` — waifu2x; `models-realcugan-se / -pro / -nose` — Real-CUGAN; `models-realesrgan-*`, `models-realesr-*`, `models-realesrnet-x4plus`, `models-nomos8ksc`, `models-lsdir-compact`, `models-nmkd-siax / -superscale` — Real-ESRGAN |
| `-n`, `--noise-level n` | уровень шума `-1` (без шумоподавления), `0`-`3` (по умолчанию 0). Real-CUGAN: 0 = бережный режим. Real-ESRGAN General: сила шумоподавления; LSDIR Compact: сила очистки; NMKD Siax: уровень деталей 0-3; остальные модели Real-ESRGAN чистят сами |
| `-t`, `--split-size t` | `0` = авто (по умолчанию), `1` = без разбиения (всё изображение одним тайлом), `2` и больше = тайлы такого размера; при нескольких GPU — по значению на каждый (`0,0`) |
| `-c`, `--sync-gap n` | Sync gap для Real-CUGAN `0`-`3` (по умолчанию 3, 0 = выкл.) |

До ИИ параметр `--deband` может сгладить бандинг исходника (в окне: Настройки > Настройки до обработки ИИ). После ИИ
изображение уменьшается до точного выходного размера (например 2,25x или ширина x высота) фильтром **после обработки**:
`-F`, `-T`, `-a`, `--dither` и `--linear-light` ниже (в окне: Настройки > Настройки после обработки ИИ). По умолчанию —
Bicubic Mitchell, без антиринга, без дизеринга, без линейного света. Ровно 2x / 3x / 4x модели сохраняется как есть.

### Фильтр без ИИ, устранение бандинга и дизеринг (`non-ai-scale`, а также до / после ИИ в режимах с ИИ)

| Параметр | Значение |
|---|---|
| `-F`, `--filter name` | `nearest`, `bilinear`, `mitchell` (по умолчанию), `catrom`, `lanczos`, `spline36`, `jinc` |
| `-T`, `--taps n` | Lanczos `2` / `3` (по умолчанию) / `4` / `8`; Jinc `3` (по умолчанию) / `4` / `8`; остальные фильтры его игнорируют |
| `-a`, `--anti-ringing a` | `off` (по умолчанию), `relaxed`, `strict`: уменьшает ореолы `catrom`, `lanczos`, `spline36` и `jinc` |
| `--linear-light` | масштабировать в линейном свете; используется только при уменьшении (ни одна сторона не растёт, хотя бы одна уменьшается) |
| `--dither d` | `off` (по умолчанию), `ordered`, `error-diffusion`: как результат округляется до 8-битного цвета. Дизеринг не даёт плавным градиентам получить новые полосы; используется при изменении размера |
| `--deband d` | `off` (по умолчанию), `low`, `medium`, `high`: **Устранение бандинга** — сглаживает полосы, которые уже есть в изображении (небо, тени, мягкие градиенты), до ИИ или фильтра без ИИ. Меняются только ровные области |

| Фильтр | Характер |
|---|---|
| `nearest` | Ближайший сосед: жёсткие ступенчатые пиксели, без размытия. Пиксель-арт при 2x / 3x / 4x |
| `bilinear` | быстро и мягко, слегка размыто, без ореолов |
| `mitchell` | Bicubic Mitchell: мягко и плавно, почти без ореолов. Надёжный выбор |
| `catrom` | Bicubic Catmull-Rom: резче, чем Mitchell, лёгкие ореолы |
| `lanczos` | резко, сохраняет мелкие детали, есть ореолы (больше отводов = резче и больше ореолов) |
| `spline36` | между Catmull-Rom и Lanczos: резко, чистые края, мало ореолов |
| `jinc` | круглый фильтр: резко, гладкие диагонали, мало ступенек; довольно медленный |

### Производительность (все режимы)

| Параметр | Значение |
|---|---|
| `-g`, `--gpu id` | используемый GPU: `0`, `1`... или `-1` для CPU (по умолчанию: первый GPU). Несколько GPU: `0,1` |
| `-j`, `--threads l:p:s` | потоки чтения : обработки : сохранения (по умолчанию `1:2:2`). Обработка = изображения одновременно на каждом GPU (1-32) или ядра CPU при `-g -1`. Два GPU: `1:2,2:2` |
| `--vram-percent p` | использовать не больше p % (20-80, по умолчанию 60) памяти GPU, свободной в начале обработки |
| `--ram-percent p` | использовать не больше p % (20-80, по умолчанию 60) RAM, свободной в начале обработки |

### Прочее

| Параметр | Значение |
|---|---|
| `-h`, `--help` | показать справку |
| `-v`, `--verbose` | выводить каждый шаг (запущенные сети, память, устройство) |
| `--list-gpu` | показать GPU с Vulkan и выйти |
| `--progress` | машиночитаемые строки прогресса (их использует окно) |

## 5. Какие параметры использует каждый режим

| Настройка в окне | Режимы с ИИ | Масштаб - без ИИ | Параметр |
|---|---|---|---|
| Входной / выходной путь, свои папки | ✓ | ✓ | `-i` `-o` (`-r`, `-l`, `-L`) |
| Формат / качество вывода | ✓ | ✓ | `-f` `-q` |
| Режим | ✓ | ✓ | `-M` |
| Уровень шума / Уровень деталей | ✓ | – | `-n` |
| Увеличение: Коэффициент, Ширина, Высота, Ширина x Высота | ✓ | ✓ | `-s` / `-W` / `-H` / `-W` + `-H` |
| Модель | ✓ | – | `-m` |
| Фильтр, Отводы, Антиринг (главное окно) | – | ✓ | `-F` `-T` `-a` |
| Вычислитель | ✓ | ✓ | `-g` |
| Размер тайла | ✓ | – | `-t` |
| Потоки | ✓ | ✓ | `-j` |
| Настройки: Sync gap для Real-CUGAN | ✓ | – | `-c` |
| Настройки: Настройки до обработки ИИ (Устранение бандинга) | ✓ | – | `--deband` |
| Настройки: Настройки после обработки ИИ | ✓ | – | `-F` `-T` `-a` `--dither` `--linear-light` |
| Настройки: Настройки фильтров без ИИ | – | ✓ | `--deband` `--dither` `--linear-light` |
| Настройки: Не перезаписывать существующие файлы | ✓ | ✓ | `-k` |
| Настройки: предел VRAM / RAM | ✓ | ✓ | `--vram-percent` `--ram-percent` |

`-F`, `-T`, `-a`, `--dither`, `--deband` и `--linear-light` — это настройки без ИИ в `non-ai-scale` и настройки до / после
обработки в режимах с ИИ: один запуск использует один режим, поэтому одного набора параметров достаточно.

## 6. Папки, списки файлов и пакетные файлы

**Папка:** `-i` — папка, `-o` — папка для записи. Каждое изображение получает то же имя с расширением выходного формата
(`-f`, по умолчанию png). С `-r` обрабатываются и вложенные папки, с той же структурой.

**Список файлов** (`-L`) переводит любые изображения в любые имена. Каждая строка — `вход`, TAB, затем `выход`:

```
D:\in\a.png	D:\out\a-2x.png
D:\in\b.jpg	D:\out\b-2x.webp
```

```
repicturer-cli.exe -L list.txt -m models-realcugan-se -s 2
```

**Пакетный файл** (`convert.bat`), который обрабатывает каждое перетащенное на него изображение и сохраняет результат рядом:

```bat
@echo off
cd /d "%~dp0"
for %%F in (%*) do (
    repicturer-cli.exe -i "%%~F" -o "%%~dpnF-2x.png" -m models-realcugan-se -s 2
)
pause
```

Сохраните его в папке RePicturer и перетаскивайте на него изображения в Проводнике.

**PowerShell**, все JPG из папки через «Масштаб - без ИИ»:

```powershell
Get-ChildItem D:\in -Filter *.jpg | ForEach-Object {
    .\repicturer-cli.exe -i $_.FullName -o ("D:\out\" + $_.BaseName + ".png") -M non-ai-scale -F lanczos -s 2
}
```

(Для большого числа изображений быстрее один запуск с папкой: модель загружается один раз.)

## 7. Коды завершения и сообщения

| Код завершения (`%ERRORLEVEL%`) | Значение |
|---|---|
| `0` | все изображения обработаны |
| `1` | часть изображений не обработана (каждое указано) |
| `-1` | обработка не началась: неверный параметр, нет модели или входа |

Изображение с ошибкой на GPU (нехватка памяти, проблема драйвера) обрабатывается заново до 2 раз: сначала 2 тайлами, затем
1 тайлом; если ошибка остаётся, обработка останавливается с сообщением. В режиме «Масштаб - без ИИ» изображение, которое GPU
не смог обработать, обрабатывается на CPU с тем же результатом.

## 8. Старые имена параметров

Имена waifu2x-ncnn-vulkan и прежних версий RePicturer по-прежнему работают, так что старые скрипты продолжают работать:

| Старое имя | Имя с v3.0 |
|---|---|
| `--noise_level` | `--noise-level` |
| `--scale_ratio` | `--scale` |
| `--scale_width`, `--scale_height` | `--width`, `--height` |
| `--tile_size` | `--split-size` |
| `--model_dir` | `--model` |
| `--jobs` | `--threads` |
| `--output_quality` | `--quality` |
| `--input_extension_list` | `--extensions` |
| `--no_overwrite`, `--file_list` | `--no-overwrite`, `--file-list` |
| `--syncgap` | `--sync-gap` |
| `-M noise_scale` / `noise` / `resize` | `-M denoise-scale` / `denoise` / `non-ai-scale` |

## 9. Решение проблем

* **«не является внутренней или внешней командой»**: командная строка открыта не в папке RePicturer. Перейдите туда через
  `cd` или укажите полный путь: `"C:\Tools\RePicturer\repicturer-cli.exe"`.
* **PowerShell пишет, что команда не найдена**: пишите `.\repicturer-cli.exe`.
* **«no vulkan device found, falling back to cpu»**: обновите драйвер видеокарты (NVIDIA, AMD или Intel). `--list-gpu`
  покажет GPU, которые видит конвертер.
* **«GPU error (probably out of GPU memory)»**: уменьшите размер тайла (`-t 200`, `-t 100`), число потоков (`-j 1:1:2`) или
  увеличьте `--vram-percent`.
* **Непонятные символы в выводе**: конвертер выводит текст в UTF-8; в старой консоли сначала выполните `chcp 65001`.
